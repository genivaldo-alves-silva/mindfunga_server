## 5.2 No terminal do servidor:
```bash
python3 -m venv env1

source env1/bin/activate

pip install psutil

#Verifique se os arquivos .sub e .py foram transferidos
ls

condor_submit testhard.sub

# verifique o status do job
condor_q

# use watch condor_q para acompanhar em tempo real a evolução do job, em hold, idle, run, etc
watch condor_q

# Quando running, use o comando abaixo para acompanhar o andamento da análise
tail -f test-h.out

# Para sair digite Ctrl+C

# explore os arquivos criados de erro e output
# use nano se preferir ao invés de cat
cat test-h.err

cat test-h.out
```

## 5.3 Veja abaixo o arquivo de submissão de exemplo (testhard.sub). O executável está inclusive já executando de dentro de um ambiente (env1).

- Veja o arquivo .sub de exemplo - [testhard.sub](./Python_Jobs/testhard.sub).
- Veja o arquivo .py de exemplo - [test-hard.py](./Python_Jobs/test-hard.py).

```sub
#testhard.sub -- RAM consuming job

executable              = /home/user/env1/bin/python3
arguments               = /home/user/test-hard.py

log                     = test-h.log
output                  = test-h.out
error                   = test-h.err

should_transfer_files   = NO

request_cpus            = 2
request_memory          = 30G
request_disk            = 5G

queue
```
