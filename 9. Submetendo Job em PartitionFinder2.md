## 9.1 Enviando arquivos para o servidor

No teu terminal (no Windows digite windows+R e em seguida cmd) do teu computador, use:
- Para acesso ao servidor veja em [cadastro](/1.%20Cadastro,%20Configuração%20e%20Primeiro%20acesso.md).

- Comandos para verificar localização, criar arquivos e editar arquivos:

```bash
# verificar novamente
ls

# deve mostrar no mínimo a presença da pasta filogenia

# entrar na pasta criada
cd filogenia

# a pasta não existe? Crie e abra-a
mkdir filogenia && cd filogenia
```
- Enviando os arquivos para o servidor

```bash
# scp -r origem destino
# a pasta filogenia já deve existir no servidor.
scp -r /home/user/Downloads/infile.fas SEU_USUARIO@server.ip.address:/home/SEU_USUARIO/filogenia/

# digite a senha do teu usuário quando requisitado
```

- Veja a matriz de exemplo - [infile.phy](./PartitionFinder2/infile.phy).
- Arquivo de configuração - [partition_finder.cfg](./PartitionFinder2/partition_finder.cfg).
- Arquivo de submissão tal como abaixo - [pfinder2_job.sub](./PartitionFinder2/pfinder2_job.sub).

## 9.2 Editando o arquivo de submissão

```sub
executable              = /opt/miniconda3/envs/pfinder2/bin/python2
arguments               = /opt/partitionfinder-2.1.1/PartitionFinder.py $(folder) --force-restart -p 8

initialdir              = $(folder)

log                     = pfinder2.log
output                  = pfinder2.out
error                   = pfinder2.err

should_transfer_files   = NO

request_cpus            = 8
request_memory          = 30G
request_disk            = 5G

queue
```

## 9.3 Submetendo o job

```bash
# se você está dentro da pasta onde todos (.phy, .sub e .cfg) os arquivos estão, você pode usar folder=./

condor_submit pfinder2_job.sub folder=pasta/onde/está/.cfg_e_.phy
```

## 9.4 Verifique o status do teu job com

```bash
condor_q

# espere alguns segundos
# deve aparecer na coluna RUN
# passou um minuto e não foi para RUN
# se estiver em IDLE pode ser que não tem recursos disponíveis e quando houver o condor se engarregará de colocar para rodar
# se estiver em HOLD, a submissão de job pede algo que não existe no servidor
# para mais detalhes você pode verificar o arquivo .err

```
