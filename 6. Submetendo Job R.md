
## 6.4 Submeta um job no seu próprio ambiente

- Mude user e tenha um Rscript.R na pasta onde salvar o envtest_R.sub abaixo.

```ini
# envtest_R.sub
# 1. Troque para o binário do Rscript
executable              = /home/user/.conda/envs/envtest/bin/Rscript
# 2. Aponte para o seu script R
arguments               = /home/user/Rscript.R

log                     = job_r.log
output                  = job_r.out
error                   = job_r.err

should_transfer_files   = NO

# Mantenha as requisições de hardware conforme a necessidade do R
request_cpus            = 2
request_memory          = 30G
request_disk            = 10G

queue
```

- Crie e salve o arquivo .sub acima

```bash
nano envtest_R.sub

# cole o conteúdo acima modificado
# Ctrl+X , Y, Enter

condor_submit envtest_R.sub

condor_q

ls

tail -f job_r.out

# Ctrl+C

cat job_r.err

cat job_r.out

```
